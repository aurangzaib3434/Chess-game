# Chess Game Project ♟️

This is a **2-player Chess Game** developed as a programming project.  
The game allows two players to play chess by following all standard chess rules.

## Features
- Two-player mode
- Complete chessboard implementation
- Valid movement for all chess pieces
- Turn-based gameplay
- Rule validation
- Interactive game flow

## Technologies Used
- C++
- Object-Oriented Programming (OOP)

## Project Description
This project was created to implement the logic of a real chess game using programming concepts.  
It demonstrates the use of **classes, objects, inheritance, and game logic implementation** to simulate a complete chess match between two players.

## How to Run
1. Clone the repository
2. Open the project in any C++ compiler/IDE
3. Compile and run the code

## Purpose
The main purpose of this project is to strengthen problem-solving skills and apply Object-Oriented Programming concepts in a real-world game development project.
